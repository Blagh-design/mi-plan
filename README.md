# Mi plan

App web para comer bien y bajar de peso con poco dinero: menús por día, recetas,
qué cocinar el domingo y cuánto aguanta en el refri, lista del súper con tope y registro de peso.

- **Funciona sin internet** y se instala en Android desde Chrome («Instalar app»).
- **Los datos se guardan solo en el teléfono** de quien la usa (IndexedDB). Este repositorio
  no tiene datos de nadie: solo el programa y recetas genéricas.
- Para respaldar, la app copia un paquete que la persona pega en su propia página privada de Claude.

Hecha con HTML, CSS y JavaScript, sin librerías. Iconos: Material Symbols de Google (licencia Apache 2.0),
solo los que usa la app (`fonts/iconos.txt`). Precios de referencia: Profeco (abril y mayo de 2026) o estimados.
